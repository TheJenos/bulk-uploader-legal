Bulk Uploader

A personal desktop tool

Bulk Uploader is a small application that runs on its owner's own computer. It uploads the owner's own short video clips to the owner's own YouTube channels and TikTok account, using the official YouTube Data API and the TikTok Content Posting API.

It is not a hosted service: there is no server, no sign-up, and no other users. Each person who runs it connects only their own accounts.

Questions: open an issue on GitHub.
